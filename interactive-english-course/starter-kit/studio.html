🔑 還沒有金鑰 📁 還沒連接資料夾 ▶ 打開播放器（開發者模式）

① 準備

1. 貼上 Gemini API 金鑰

到 Google AI Studio 登入 Google 帳號，按 Create API key，把那一整串複製下來貼在這裡。

🔒 金鑰就像你的信用卡號碼。工作台只把它存在這個瀏覽器裡，不會寫進任何檔案。 請不要把金鑰貼到題庫檔、README 或任何會上傳到 GitHub 的地方，也不要傳給別人。

2. 連接專案資料夾（建議用 Chrome 或 Edge）

按下面的按鈕，選擇 starter-kit 這一層資料夾（打開後會看到 index.html、studio.html、content、assets）。 連接之後，產生的聲音和圖片會直接存進正確的位置，檔名也會自動取好。

瀏覽器會問「要允許這個網站編輯檔案嗎？」，請按允許。不連接也可以用（下載模式）：產生的檔案會先留在這一頁，最後打包成一個 zip 下載， 再自己解壓縮到 starter-kit 資料夾裡。

3. 模型（通常不用改）

Google 推出新模型時，只要把名字換掉就好，其他都不用改。這就是把「設定」和「程式」分開的好處。
